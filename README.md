# UON-EOMS (UON Electoral & Organization Management System)

A production-ready web platform tailored for University of Nairobi student organizations.

## Tech Stack
- **Backend:** Rust (Actix-Web), Diesel, PostgreSQL
- **Frontend:** Next.js (React), TypeScript
- **Infrastructure:** Docker, Docker Compose

## Getting Started

1. Make sure you have Docker and Docker Compose installed.
2. Run the following command in the root directory:
   \`\`\`bash
   docker-compose up --build
   \`\`\`
3. The application will be available at:
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8080
   - Database: localhost:5432

## Features Implemented in MVP
- PostgreSQL Schema for Users, Faculties, Departments, Organizations, Positions, Candidates, and Votes.
- Rust Backend setup with Diesel migrations and connection pooling.
- Next.js frontend scaffold.
- Docker-compose orchestration for seamless deployment.
